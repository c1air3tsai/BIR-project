# Project #3 研究問題回答（RQ1–RQ5）

> 資料：3000 篇 GLP-1 PubMed 摘要（每篇都有 MeSH）。前處理：tokenize、lowercase、去標點、移除 stopword、不做 stemming。
> 查詢：12 個，相關性依 MeSH 標註判定（Major Topic = 2 分，其他相關 = 1 分）。
> 數字皆由 `python manage.py run_weighting_experiments` 產生，原始檔在 `docs/project3_results/`；完整說明見 `docs/project3_report.md`。

---

## RQ1：原始 TF 與 Log TF 的差異，如何影響文件的詞項權重？

**回答**：Raw TF 讓權重與出現次數成正比；Log TF = 1 + log10(tf)，tf 每增加 10 倍權重只多 1。

| tf | Raw TF | Log TF |
|---|---|---|
| 1 | 1 | 1.000 |
| 10 | 10 | 2.000 |
| 22（insulin，PMID 24589127） | 22 | 2.342 |
| 34（glp-1，PMID 24267262） | 34 | 2.531 |

- 無 L2 時，Log TF 的 nDCG@10 是 0.814，Raw TF 是 0.729。
- Raw TF 容易被重複最多的常見詞主導：查「GLP-1 obesity weight loss」時，Raw TF 的第 1 名是把 glp-1 重複 34 次的動脈粥狀硬化論文；Q05（副作用與安全性）的前 10 名全是 glp-1 重複 10–34 次的文件，0 篇相關。
- 但當查詢詞就是文章主題時（如 Q03 liraglutide），Raw TF 反而最高（0.649）。

## RQ2：為什麼 IDF 能降低常見詞的重要性，並提高較具辨識力詞項的權重？

**回答**：IDF = log10(N / df)。出現的文件越多，IDF 越接近 0；只出現在少數文件的詞，IDF 越大。

| 高 DF 詞 | DF | IDF | | 低 DF 詞 | DF | IDF |
|---|---|---|---|---|---|---|
| glp-1 | 2955 | 0.007 | | gzr18 | 3 | 3.000 |
| glucagon-like | 2355 | 0.105 | | visfatin | 3 | 3.000 |
| diabetes | 1534 | 0.291 | | gdf15 | 5 | 2.778 |
| receptor | 1484 | 0.306 | | mafld | 5 | 2.778 |
| insulin | 1182 | 0.405 | | l-arginine | 5 | 2.778 |

- 語料本來就是用 GLP-1 搜尋出來的，`glp-1` 出現在 98.5% 的文件，IDF 只有 0.007，無法區分文件。
- 同一篇文件內：`glp-1` 出現 34 次，TF-IDF 只有 0.223；`semaglutide` 出現 10 次，TF-IDF 是 10.844，高出約 49 倍。
- 限制：低 DF 詞也包含縮寫或藥物代號（如 gzr18、xglp），IDF 高不一定代表有意義。

## RQ3：相較於只使用 TF 或只使用 IDF，TF-IDF 是否能產生較好的搜尋排名？

**回答**：大致是，尤其相對於只用 IDF。

| 比較（nDCG@10） | 無 L2 | 勝 / 負 / 平 | 有 L2 | 勝 / 負 / 平 |
|---|---|---|---|---|
| TF-IDF vs Raw TF | 0.829 vs 0.729 | 9 / 1 / 2 | 0.785 vs 0.731 | 6 / 4 / 2 |
| TF-IDF vs IDF only | 0.829 vs 0.531 | 11 / 1 / 0 | 0.785 vs 0.630 | 10 / 2 / 0 |
| Log TF-IDF vs Log TF | 0.842 vs 0.814 | 5 / 2 / 5 | 0.712 vs 0.734 | 5 / 6 / 1 |
| Log TF-IDF vs IDF only | 0.842 vs 0.531 | 12 / 0 / 0 | 0.712 vs 0.630 | 9 / 2 / 1 |

- **IDF only 最差**：只看詞有沒有出現，提到一次與整篇討論同分；單一詞的查詢（Q02、Q08）幾乎沒有排序能力（nDCG 0.253、0.143）。
- **相對於只用 TF**：無 L2 時 TF-IDF、Log TF-IDF 都較好；有 L2 時 Log TF-IDF 略低於 Log TF。
- 整體最佳：Log TF-IDF（無 L2）nDCG@10 0.842；TF-IDF（無 L2）P@5 0.933、P@10 0.908。

## RQ4：文件向量是否需要進行 L2 normalization？正規化前後的排名有何差異？

**回答**：要做 cosine similarity 就需要 L2，而且它會大幅改變排名；但在本資料集中，它只對部分方法有幫助。

| 方法 | Top 10 平均長度（無 L2 → 有 L2） | Top 10 重疊 | nDCG@10（無 L2 → 有 L2） |
|---|---|---|---|
| Raw TF | 180.6 → 137.2 | 5.5 / 10 | 0.729 → 0.731 |
| Log TF | 171.8 → 97.7 | 3.6 / 10 | 0.814 → 0.734 |
| IDF | 139.1 → 89.5 | 3.3 / 10 | 0.531 → 0.630 |
| TF-IDF | 176.1 → 127.2 | 5.2 / 10 | 0.829 → 0.785 |
| Log TF-IDF | 171.6 → 98.3 | 3.0 / 10 | 0.842 → 0.712 |
| BM25 | 143.3 → 105.8 | 5.3 / 10 | 0.797 → 0.719 |

（全語料平均長度 143.2 tokens）

- 無 L2 時，Top 10 偏向長文件；L2 後偏向短文件，約一半以上的 Top 10 被替換。查「GLP-1 obesity weight loss」用 Log TF-IDF 時，兩邊 Top 10 完全沒有重疊（0 / 10），L2 的第 1 名只有 50 tokens。
- L2 只讓 Raw TF（+0.002）與 IDF（+0.099）變好；其他四種都下降，Log TF-IDF 降最多（−0.130）。BM25 已有長度正規化，再加 L2 等於重複懲罰長文件。
- 可能原因：L2 後排名主要看查詢詞的「密度」，短摘要只要提到查詢詞就排很前面（相關與不相關文件的平均長度其實差不多，147 vs 143 tokens）。

## RQ5：不同 weighting 方法對 Precision@k、MRR 或 nDCG 等指標有何影響？

| 組合 | P@5 | P@10 | Recall@10 | MRR | nDCG@10 |
|---|---|---|---|---|---|
| Raw TF（無 L2 / L2） | 0.800 / 0.783 | 0.800 / 0.825 | 0.056 / 0.061 | 0.878 / 0.879 | 0.729 / 0.731 |
| Log TF | 0.850 / 0.867 | 0.892 / 0.833 | **0.067** / 0.063 | 0.931 / **1.000** | 0.814 / 0.734 |
| IDF | 0.600 / 0.767 | 0.600 / 0.683 | 0.048 / 0.048 | 0.826 / **1.000** | 0.531 / 0.630 |
| TF-IDF | **0.933** / 0.917 | **0.908** / 0.883 | 0.065 / 0.064 | 0.958 / 0.917 | 0.829 / 0.785 |
| Log TF-IDF | 0.917 / 0.850 | 0.900 / 0.808 | 0.066 / 0.056 | **1.000** / 0.958 | **0.842** / 0.712 |
| BM25（額外比較） | 0.900 / 0.833 | 0.867 / 0.817 | 0.065 / 0.059 | 0.958 / 0.958 | 0.797 / 0.719 |

- **P@5／P@10**：TF-IDF（無 L2）最高，IDF only 最低。
- **MRR**：多數 ≥ 0.92，三個組合達 1.000；但 MRR 只看第一篇相關文件，例如 IDF + L2 的 MRR 是 1.000，nDCG 卻只有 0.630。
- **nDCG@10**：最能區分方法，Log TF-IDF（無 L2）最高。
- **Recall@10**：相關文件多（47–648 篇），上限只有 0.072，各方法差異很小。
- 不同指標的最佳方法不同，12 個查詢的最佳方法也分散在六種方法之間。

## 結論：從實驗中學到的四件事

| 學習重點 | 實驗證據 |
|---|---|
| **詞頻增加，不代表詞的重要性會等比例增加** | tf 從 1 到 22，Log TF 權重只增加到 2.34 倍；無 L2 時 Log TF 的 nDCG@10（0.814）高於 Raw TF（0.729）；Raw TF 被重複 34 次的 glp-1 帶偏，Q05 的 nDCG = 0 |
| **出現在許多文件中的詞，通常較缺乏區分文件的能力** | glp-1 出現在 2955 / 3000 篇，IDF 只有 0.007；低 DF 詞 IDF 2.8–3.0；加上 IDF 的 TF-IDF 在 12 個查詢中有 11 個勝過只用 IDF |
| **文件向量的正規化會影響相似度計算及排名** | 有無 L2 的 Top 10 平均只有 3–5.5 篇相同；Top 10 平均長度從 139–181 降到 89–137 tokens |
| **不同 weighting 方法的優劣，必須結合查詢、資料集與評估指標判斷** | P@k 最好是 TF-IDF、nDCG 最好是 Log TF-IDF、MRR 三組並列；同一套方法在 1000 篇時 TF-IDF + L2 最好，3000 篇時變成無 L2 的 Log TF-IDF 最好 |

**限制**：相關性來自 MeSH 規則而非人工判讀；只有 12 個查詢，未做顯著性檢定；語料集中在 GLP-1 主題，只取 PubMed 相關度前 3000 篇。
